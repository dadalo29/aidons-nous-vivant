# Aidons Nous Vivant — Site web

Site vitrine de l'association humanitaire **Aidons Nous Vivant (ANV)** — Sénégal.

Association à but non lucratif, non confessionnelle, non clanique et apolitique.
Domaines d'action : **Santé · Éducation · Environnement**.

## Contenu

Site statique, une seule page, responsive et accessible.

- `index.html` — la page (HTML + CSS + JS, tout-en-un)
- `images/` — logo officiel (SVG), photos HD des actions

## Mise en ligne

Site 100 % statique : il suffit d'envoyer `index.html` et le dossier `images/`
à la racine de l'hébergement (IONOS, Gandi, Netlify, GitHub Pages…), puis de
pointer le domaine **anv-asso.org** dessus.
